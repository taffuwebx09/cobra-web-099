INSTALLATION & REFERENCE

Approved Extension Required

To use the Cobra Return Address workflow, install the approved Chrome extension and enable it for the Cobra website. This package connects the page to your already-authenticated Delhivery RPC session; it does not ask for or store your RPC password.

DOWNLOAD CHROME EXTENSION (.ZIP)
01 · ExtractExtract the downloaded ZIP into a folder you can keep on this computer.
02 · Open ExtensionsIn Chrome, open chrome://extensions and turn on Developer mode.
03 · Load unpackedClick “Load unpacked” and select the extracted extension folder containing manifest.json.
04 · Allow site accessSet extension site access to the Cobra website, then refresh Cobra. Sign in to Delhivery RPC in the same Chrome profile.
Security notice: Install only the extension package provided by your developer. This browser-side extension check is an access gate for the user interface, not strong server-side authentication. Do not treat the page URL or extension check as protection for confidential data by itself.
